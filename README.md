# Spanish Market Greenwashing Detector 🌿🔍

An Unsupervised Machine Learning pipeline designed to detect potential greenwashing anomalies and misleading environmental claims in commercial food products within the Spanish market.

---

### 🛠️ Tech Stack & Libraries

- **Language:** Python 3.x
- **Data Processing & Analysis:** Pandas, NumPy
- **Machine Learning & Clustering:** Scikit-learn (K-Means, DBSCAN, PCA / Anomaly Detection)
- **Data Visualization:** Matplotlib, Seaborn
- **Data Source:** Open Food Facts Dataset (Spanish Market subset)

---

### ✨ Project Overview

Consumer markets are flooded with products making "eco-friendly", "organic", or "sustainable" claims without standard certifications. This project leverages unsupervised clustering and statistical anomaly detection algorithms to cross-examine sustainability claims against actual product nutrition and environmental scores (e.g., Nutri-Score, Eco-Score).

#### Key Features
- **Data Cleaning & Normalization:** Ingestion, cleaning, and feature engineering on high-dimensional product datasets.
- **Unsupervised Anomaly Detection:** Identifies products with high environmental marketing claims but poor objective sustainability metrics.
- **Clustering Analysis:** Groups similar products to establish baseline environmental ratings within specific categories.
- **Exploratory Data Analysis (EDA):** Visualizations highlighting greenwashing patterns and statistical outliers.
